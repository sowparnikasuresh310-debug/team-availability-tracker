# 🌟 TeamFlow – Team Availability Tracker

TeamFlow is a web-based **Team Availability Tracker** built using Flask. It allows teams to monitor the availability of members in real time through a simple and interactive dashboard.

The application provides multiple availability statuses, user management, search and filtering, authentication, and an admin dashboard for managing team members.

---

## 📌 Project Overview

TeamFlow was developed to understand how a web application can synchronize **frontend interactions with backend database updates**.

The main purpose of the application is to provide a centralized dashboard where team members can view and manage their availability.

### Key Features

- 🔐 User Login and Authentication
- 👑 Admin Access and Management
- 👥 Team Member Management
- 🟢 Multiple Availability Statuses
- 🔄 Database-synchronized Status Updates
- 🔎 Search Team Members
- 🏷️ Filter by Status
- 👤 Filter by Role
- 📊 Team Availability Statistics
- ✏️ Edit Team Member Information
- 🗑️ Delete Team Members
- 🌙 Dark Mode
- 🎨 Modern Gradient User Interface
- 📱 Responsive Layout
- 🔔 Interactive UI elements and status indicators
